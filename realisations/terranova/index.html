Terranova — un Basecamp sur mesure pour les Semisto Hubs

Plateforme collaborativeSemisto · 2026Rails 8.1 Hotwire Tailwind CSS 4 PostgreSQL Solid Queue PWA

Le contexte

Semisto veut transformer l'Europe en forêts comestibles — via des hubs locaux qui répliquent le modèle wallon : formations, bureau d'études, pépinière-école. Chaque hub est une équipe, avec ses projets, ses bénévoles et ses outils.

Le besoin

Basecamp était l'outil rêvé pour la culture d'équipe de Semisto — mais il ne connaît ni les palettes végétales, ni les plans de plantation, ni les hubs multiples, ni les membres IA. Il fallait le meilleur des deux : la sobriété de Basecamp, plus le métier des forêts comestibles.

La solution

Terranova, une réécriture greenfield en Rails 8 et Hotwire, architecturée comme Basecamp : chaque contenu — message, to-do, carte, document — est un « recording » dans un projet, ce qui donne gratuitement commentaires, mentions, boosts, corbeille, recherche et API à tous les outils. Multi-hubs par construction : un compte, plusieurs hubs, isolation stricte. Les outils classiques répondent présent — annonces, to-dos avec hill charts, chat temps réel, calendrier, documents — et les outils métier s'y ajoutent : palettes végétales par strates, plans de plantation, catalogue botanique. Nova, le membre IA, rejoint les projets où on l'invite. Le tout exposé par une API privée avec spécification OpenAPI générée en direct, et installable en PWA.

Le résultat

Une plateforme que l'équipe wallonne utilise au quotidien et que chaque futur hub européen recevra clé en main : la méthode Basecamp, le métier Semisto, et une IA membre de l'équipe. Les captures tournent sur une instance de démonstration remplie de données fictives.
